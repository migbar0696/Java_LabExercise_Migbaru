# Java_LabExercise_Migbaru


This repository contains multiple Java projects built to practice desktop application development, GUI design, networking, game logic, and database integration.

## Projects Included

### 1. Java Notepad App
A simple text editor built using Java Swing.

#### Features
- Create and edit text files
- Open and save files
- Simple GUI interface
- Basic text editing features

#### Technologies
- Java
- Swing

---

### 2. Java Poker Game
A Poker game where the player competes against the computer.

#### Features
- Player vs Computer gameplay
- Card dealing system
- Poker hand evaluation
- Interactive GUI
- Game logic implementation

#### Technologies
- Java
- Swing
- OOP Concepts

---

### 3. Java Swing Chat Application
A real-time chat application with authentication and database integration.

#### Features
- User registration and login
- Multiple user accounts
- Real-time messaging
- Image upload and sharing
- Online users support
- Message storage using MySQL
- GUI chat interface

#### Technologies
- Java
- Swing
- Socket Programming
- JDBC
- MySQL

---

# Technologies Used
- Java
- Swing
- JDBC
- MySQL
- Socket Programming
- Multithreading
- Object-Oriented Programming (OOP)

# How to Run
1. Clone the repository
2. Open the project in your preferred IDE
3. Configure MySQL for the chat application
4. Run the main Java files for each project

# Purpose
These projects were built to improve skills in:
- Java programming
- GUI development
- File handling
- Networking
- Database integration
- Game development
- Object-oriented programming
